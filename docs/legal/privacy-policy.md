## 1. 수집 항목과 목적

| 구분 | 항목 | 목적 |
|---|---|---|
| 가입(필수) | 이메일, 비밀번호(암호화 해시로만 저장), 닉네임 | 회원 식별, 로그인 |
| 러닝 기록 | 위치 경로(GPS 좌표), 거리, 페이스, 기록 시각 | 러닝 기록·공유 |
| 선택 입력 | 사진(러닝당 최대 3장), 코스 소개 | 러닝 기록 공유 |
| 안전 | 신고 내역(신고자, 대상, 사유, 시각), 차단 목록 | 부적절 콘텐츠 대응 |
| 자동 생성 | 로그인 토큰, 접속 IP·기기 정보 [확인 필요: 서버 로그 보관 여부] | 로그인 유지, 보안 |

러닝 기록(경로·거리·페이스·사진·코스 소개)과 닉네임은 **다른 이용자에게 공개**됩니다.
