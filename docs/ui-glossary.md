# UI 용어 사전 (우디디자인랩 UI 미니 사전 기준)

출처: https://woodydesignlab.com/ui/dict (2026-11-19 확인, 10개 분류 90개 용어)

이 프로젝트에서 화면 요소를 부를 때는 아래 **표준 용어**만 씁니다. 「일상어」 열은 사전 페이지가 검색용으로 달아 둔 말이며, 비개발자가 흔히 쓰는 표현입니다. 이 말이 나오면 표준 용어로 바꿔 부릅니다.

사전에 없는 요소(예: 칩, 카드, 마커)는 임의로 새 이름을 만들지 않고 「사전에 없음」으로 표시한 뒤 이 문서의 「사전에 없는 요소」 표에 추가합니다.
